# Alat bantu

`check_contract.py` memeriksa kontrak parameter, menghasilkan ulang contoh/tabel dengan `--sync`, serta memeriksa env per peran atau pasangan tanpa mencetak nilai rahasia. Gunakan `python3 scripts/check_contract.py --help` dan [panduan kontrak](../docs/interface-contracts/index.md). Alat ini memakai Python standard library dan tidak mengubah VM atau env privat.

Alat pengembangan lain ditambahkan sesuai kebutuhan. Skrip pemasangan guest berada di `deployment/`; screenshot yang disebut VMware tetap berasal dari capture VMware asli, bukan output skrip.
