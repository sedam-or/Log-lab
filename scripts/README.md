# Alat bantu pengembangan

Simpan alat bantu pemeriksaan lokal, validasi dokumen, ekspor diagram, dan pengumpulan evidence yang aman di sini ketika tersedia. Skrip pemasangan dan konfigurasi guest berada di `deployment/`.

Skrip harus menjelaskan prasyarat, lokasi dijalankan, input, keluaran, dan kode keluar saat gagal. Jangan menyisipkan password/token atau mengganti screenshot VMware dengan gambar buatan. Output terminal dan capture VMware diberi label sesuai sumbernya.
