# Kebutuhan

Mulai dari [PRD](PRD.md) untuk memahami masalah, pengguna, hasil, dan batas proyek. Setelah itu buka [indeks SRS](srs/index.md) untuk kontrak teknis yang diperlukan oleh tugasmu. Markdown merupakan sumber yang diedit; PDF akan dibangun ulang setelah review isi.

PRD dan SRS diadaptasi dari dokumen proyek sebelumnya. Persetujuan historis produk, status draf teknis, dan hasil uji implementasi lama tetap dibedakan. Jangan memakai angka acceptance lama sebagai hasil Erna, Arhasya, atau repo baru.

Dokumen lain dan status migrasinya tercatat di [inventaris](../history/inventory.md). Tugas pelaksanaan mengacu pada [panduan anggota](../tasks/index.md).
