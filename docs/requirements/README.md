# Kebutuhan produk dan sistem

Direktori ini akan memuat `PRD.md` dan `SRS.md` yang diselaraskan untuk repo Log-lab. Keduanya belum diterbitkan di sini. PRD dan SRS dari workspace praktikum sebelumnya merupakan bahan migrasi, dengan status dan batas evidence yang harus dipertahankan secara jujur.

PRD menjelaskan masalah, pengguna yang relevan, hasil, lingkup, dan kriteria keberhasilan. SRS merinci peran VM, state, kontrak teknis, konfigurasi, kualitas layanan, dan metode verifikasi. Dokumen kontrak di `../interface-contracts/` menyediakan schema, fixture, serta contoh yang diturunkan dari SRS. Jika definisinya berbeda, selaraskan sebelum baseline diterima.

ID EP (Event Pipeline), AA (Activity Analysis), ML (Machine Learning), UI (Operator Console), dan OP (Lab Operations) dari baseline terdahulu dipertahankan saat migrasi. Setiap istilah dijelaskan ketika pertama dipakai. Perubahan produk dimulai di PRD; rincian teknis mengikuti di SRS. Task dan PDF panduan mengacu pada keduanya.

Task penerbitan dan kriteria selesai ada di [D-02](../TASKS.md). Dokumen ini tidak menyatakan persetujuan dosen atau hasil acceptance pada repo baru.
