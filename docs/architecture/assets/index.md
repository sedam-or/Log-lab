# Assets arsitektur

Sumber `.mmd` dan render `.svg`/`.png` dipindahkan dari dokumen proyek lama. Gambar PNG paket Modul 3 berorientasi landscape. Tidak ada screenshot VM di folder ini.

- `PRD_ALUR_PRODUK`: alur login sampai tinjauan operator.
- `SRS_VM_DAN_KOMUNIKASI`: komponen dan komunikasi dua VM; narasi target host terkini ada di baseline.
- `SRS_ALUR_EVENT`: commit, kirim, receipt, dan analisis.
- `SRS_PETA_KEMAMPUAN`: dependensi lima kemampuan.
- `logical-architecture`: pembagian logis Source dan Monitor.
- `physical-deployment-architecture`: dua guest pada host Windows 11.

Gunakan [halaman arsitektur](../index.md) untuk membaca gambar dalam konteks. Bila narasi baseline mengubah isi diagram, tandai dan render ulang sebelum publikasi PDF final.

[Diagram proses kerja untuk pemula](learning/index.md) menjelaskan host/SSH, perjalanan event, Git, task peran dan integrasi.
